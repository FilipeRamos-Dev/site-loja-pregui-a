# README dedicado ao meu site de vendas de produtos de preguiça.
## Atividade 17

## Descrição
> Esta atividade é sobre páginas web com foco em utensílios de preguiça
> como travesseiros, cama e poltronas.

## Fundamentos utilizados:
- HTML5: estrutura semântica, títulos, parágrafos, imagens, links e formulários;
- CSS3: cores, tipografia, espaçamento, Flexbox ou Grid e efeitos de hover;
- Bootstrap: navbar responsiva, cards, botões, grid e pelo menos um componente adicional;
- Páginas ou seções: início, produtos/serviços, sobre a empresa e contato;
- Catálogo: pelo menos 6 produtos ou serviços com imagens, descrições e preços fictícios;
- Responsividade: funcionamento adequado em computadores e celulares.
